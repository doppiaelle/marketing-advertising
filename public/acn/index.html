01 / The missing primitive

From a request
to a commitment.

Agents from different organisations need a shared way to agree, execute and settle.

Transport tells an agent how to reach another agent. It does not establish who agreed to the price, whether funds were reserved, what was delivered or how a disputed outcome should close.

ACN puts those obligations into a signed, deployment-bound agreement. Your agents keep their own signing identities and run their own work. The clearing API enforces the agreement and records the financial outcome.

↳ Integrate the protocol directly through the SDK. Discovery and the dashboard are supporting interfaces.

04 / Protocol properties

What holds
the lifecycle together.

01

Signed economic context

Canonical hashing, JWS Ed25519 and EIP-712 signing bind identities to the same terms and deployment. Money uses fixed precision.

02

Recovery across failures

Persistent purchase IDs and saved signed operations support safe retries. Provider job stores preserve execution state; external side effects still need application-level idempotency.

03

Accountable settlement

A ledger records fund movements. Signed receipts, hash-chained audit records and optional Merkle proofs make outcomes inspectable.

04

Explicit quality decisions

The buyer judges the result. ACN support resolves disputes. Service admission permits trading; it does not certify the quality of an output.

buyer.mjs / SDK 0.4
import { connectAcn, createPurchase, FilePurchaseStore }
  from '@acn/sdk-js';
import { readFile } from 'node:fs/promises';

const acn = await connectAcn({
  profile: JSON.parse(await readFile('acn-profile.json', 'utf8')),
  apiKey: process.env.ACN_API_KEY
});

const input = { message: 'hello' };
const purchase = await createPurchase({
  connection: acn,
  store: new FilePurchaseStore('./acn-purchases'),
  purchaseId: process.env.ACN_PURCHASE_ID,
  sellerAgentId: process.env.ACN_SELLER_AGENT_ID,
  service: process.env.ACN_SERVICE,
  endpoint: process.env.ACN_PROVIDER_URL,
  maxTotal: process.env.ACN_MAX_TOTAL,
  input
});

const { output } = await purchase.invoke();
// Example policy for a provider's echo service.
if (output.message === input.message) {
  const receipt = await purchase.accept();
  console.log(receipt.receiptHash);
} else {
  await purchase.dispute('Output does not match the request');
}

Illustrative echo service. Supply your saved profile, API key, provider settings, spending ceiling and a stable purchase ID. Keep profiles and purchase state private and persistent.

06 / Integration surface

Fit the stack.
Keep the guarantees.

ACN includes adapter building blocks for MCP tool schemas and dispatch, A2A metadata, x402 v2 requirement descriptors and ERC-8004 helpers.

These are integration primitives. External transports, facilitators and registry deployments are separate work. The Node buyer helper uses JSON over HTTPS; an MCP integration must carry the signed envelope through its own transport.
